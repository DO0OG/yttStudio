# PROGRESS.md

> **문서 기준:** v0.2.5 (2026-08-30)

## v0.2.5 — YouTube 재생 준비 결함 수정

- Deno/libmpv 자동 설치: 다운로드 스트림이 열린 채 SHA-256 검증용으로 같은 파일을 다시 열어 항상 실패하던 파일 잠금 결함 수정
- yt-dlp: 기존 설치본을 무조건 재사용하지 않고 `--js-runtimes` 지원 여부를 확인한 뒤에만 재사용, 아니면 고정 공식 자산 설치
- 정리: 중단된 설치가 남긴 `.deno-install-*` 임시 폴더를 다음 설치 시작 시 제거
- 회귀 테스트: 다운로드 경로 파일 핸들과 yt-dlp 지원 게이트를 실제로 실행하는 테스트 추가 (기존 테스트는 리플렉션 계약 확인만 했다)
- 검증: Windows x64에서 실제 자산 다운로드부터 공개 YouTube VOD 메타데이터 추출까지 통과, 전체 테스트 391개 통과

## v0.2.3 릴리스 준비 — 영상 런타임/배포 컴플라이언스

- libmpv: Shinchiro 기본 GPL 계열 자동 설치를 제거하고 지원 플랫폼별 검증 런타임 pin으로 교체
- 첫 영상 열기: libmpv 부재 상태에서도 명령을 열어 두고 프로그램 내부 설치 후 원래 요청 계속

| 프레임 후진 | `frame-back-step` |

### 고친 것

| 문제 | 원인 | 해법 |
|---|---|---|
| 상단 메뉴와 패널이 검은 띠로 보임 | `MainWindow.axaml` 에 다크 전용 색상 리터럴 40여 곳이 하드코딩되어 있는데 앱은 시스템 기본(라이트) 테마로 실행됨 | `App.axaml` 의 Light / Dark `ThemeDictionaries` 리소스로 치환 |

### 추가한 것

- **환경설정 창** — 탭 구성(일반 / 모양 / 영상). 언어, 테마, libmpv 경로와 자동 설치,
  자동 저장 사용 여부와 간격을 설정하고 `%LOCALAPPDATA%\YttStudio\preferences.json` 에 저장
- **테마** — 시스템 기본 / 라이트 / 다크, 재시작 없이 전환
- **패널 크기 조절** — 좌·우 패널 너비와 영상 / 타임라인 / 자막 목록 높이를 `GridSplitter` 로 조절
- **볼륨** — 음소거 토글과 볼륨 슬라이더, 설정에 영속화
- **재생 버튼 아이콘** — 정지 중 `▶`, 재생 중 `⏸`

### libmpv 라이선스 결정

공식 Windows mpv 빌드는 **GPLv2+** 다. 배포물에 `libmpv-2.dll` 을 포함하면 GPL 이 전파될 수
있으므로 **번들하지 않는다.** 반면 앱이 실행 중에 사용자의 명시적 동의를 받아 내려받는 것은
배포 행위가 아니므로 전파되지 않는다. 따라서 자동 설치는 출처와 라이선스를 표시하고
사용자가 버튼을 눌렀을 때만 동작하며, 설치 위치는 사용자의 로컬 앱 데이터 폴더다.
macOS 와 Linux 에서는 자동 설치 대신 패키지 매니저 명령을 안내한다.

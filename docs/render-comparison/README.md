# 렌더 비교 및 tolerance 기록

내장 미리보기는 **편집용 고품질 근사치**다. 픽셀 완전 일치를 목표로 하지 않는다.
최종 확인은 실제 플레이어 프리뷰로 한다.

`m1-render.png` — M1 렌더러가 실제로 출력한 결과 (기동 검증용).

`m2-canvas.png` — 프리뷰 인라인 편집 상태. 선택 박스의 바깥 조절점 여덟 개와 가운데 앵커
점, 제자리 편집 중인 텍스트가 보인다. 영상을 열지 않은 상태라 프리뷰 배경은 비어 있다.

`m3-effects.png` — 속성 패널의 효과 섹션을 펼친 상태 (이동 / 페이드 / 흔들림 / 색수차).

> 두 캡처 모두 현재 UI(메뉴 바 + 설정 버튼)를 반영한다. UI 구조가 바뀌면 함께 갱신한다.

---

## ⚠️ 현재 tolerance는 대부분 잠정값(provisional)이다

**M1 완료 조건은 "실제 유튜브 플레이어 스크린샷과 대조해 관측된 편차를 기록한 뒤
그 분포를 근거로 tolerance를 확정한다"이다. 그 측정은 아직 수행되지 않았다.**

| 항목 | 값 | 지위 |
|---|---|---|
| 폰트 크기 공식 왕복 오차 | 0 (정확히) | **확정** — 포맷 공식의 역산이라 실측 불필요 |
| 좌표 왕복 오차 | ≤ 1px @ 1280×720 | **확정** — 포맷 공식의 역산이라 실측 불필요 |
| 앵커 스크린 좌표 오차 | ≤ 1.0px @ 1280×720 | **잠정** — 실측 미수행 |
| 큐 bounding box 위치 오차 | ≤ 1.0px @ 1280×720 | **잠정** — 실측 미수행 |

**왕복 오차만 확정이다.** 좌표와 폰트 배율의 upstream 공식을 역산하는 것이라
실제 플레이어와 무관하게 수학적으로 검증된다.
반면 **앵커·박스 위치**는 유튜브가 실제로 어디에 그리는지와 대조해야 하므로 잠정이다.
잠정값을 만족한다고 해서 "유튜브와 일치한다"는 뜻이 **아니다.**

## 확정 절차 (미수행 — `[EMPIRICAL]`)

`docs/YTT-VERIFICATION.md` E-8과 연결된다.

1. **기준 fixture 작성** — `samples/anchor-grid.ytt`
   - `ap` 0~8 각각에 `ah`/`av`를 알려진 값(10 / 50 / 90)으로 고정한 큐 9개
   - 폰트는 **번들 Roboto(`fs=0`)만** 사용해 로컬 폰트 차이를 배제
   - `sz=100`, 단일 줄, 효과 없음 — 변수를 하나씩만 움직인다
2. **업로드 후 스크린샷** — 1280×720 영상에 적용하고 PC 브라우저에서 캡처.
   일반 / 극장 / 전체화면을 각각 기록하고, 모바일 세로 화면은 별도 기기 또는 동일한
   CSS viewport의 재현 환경에서 캡처한다. 브라우저·OS·플레이어 크기·영상 콘텐츠 영역·
   확대 배율(100% 고정)·캡처 시각을 함께 기록한다
3. **좌표 측정** — 각 자막 박스의 좌상단·중심 픽셀 좌표와 다음 필드를 이미지에서 읽는다.
   `PlayerSize`, `VideoContentRect`, `SubtitleSpace`, `PreviewViewportMode`.
   `SubtitleSpace`는 알려진 `ah=0/50/100` 픽스처의 실제 위치로부터 역산하고,
   검은 여백을 포함하는지 여부를 별도로 기록한다
4. **편차 계산** — `ISubtitleRenderer.Measure()` 결과와 비교
5. **분포 기록** — 9개 앵커 × 일반/극장/전체화면/모바일 모드의 편차를 이 문서에 표로 남긴다
6. **tolerance 확정** — 관측 분포를 근거로 값을 정하고 위 표의 "잠정"을 "확정"으로 바꾼다
7. 확정값을 이 문서의 tolerance 표에 기록한다

측정 이미지는 이 디렉터리에 `youtube-<mode>-<date>.png` 로 보관한다.

## 왜 이 작업이 필요한가

측정 없이 뷰포트 좌표 동작을 추측으로 구현해서는 안 된다.
특히 **극장 모드에서 `ah`는 좌우 검은 여백을 포함한 전체 폭 기준**이 되므로
(`[UPSTREAM]`), 중앙에서 벗어난 자막이 화면 밖으로 밀릴 수 있다.
`PlayerViewport` 의 `SubtitleSpace` ⊃ `VideoContentRect` 관계를 구현하려면
실측 수치가 반드시 있어야 한다.

**측정 전까지 `PreviewViewportMode`는 `VideoFrame`만 활성화하고
나머지는 UI에서 비활성 + "측정 대기 중"으로 표시한다.**

## raster golden 테스트의 범위 제한

golden PNG는 **번들 폰트만 사용하는 케이스로 한정**한다.
시스템 폰트(Lucida Console `fs=3`, Comic Sans MS `fs=5`, Monotype Corsiva `fs=6`)에
의존하는 golden은 개발자 머신마다 깨진다. 그런 케이스는 layout test와 smoke test로만 검증한다.

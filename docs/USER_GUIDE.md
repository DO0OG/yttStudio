# YttStudio 사용자 가이드

YouTube YTT(SRV3) 자막 전용 WYSIWYG 에디터. 영상 위에서 직접 배치·스타일링하고 `.ytt`를 뽑습니다.

> **언어 / Language / 言語** — 도구 → 설정 → 일반에서 한국어 · English · 日本語를 전환합니다.
> 전환은 즉시 반영됩니다.

---

## 1. 시작하기

### 필요한 것

| 항목 | 비고 |
|---|---|
| .NET 10 런타임 | self-contained 빌드를 쓰면 불필요 |
| libmpv | **영상 재생에만 필요.** 없어도 자막 편집·저장은 정상 동작 |

### libmpv 없이 쓰기

libmpv를 찾지 못하면 영상 대신 **단색/체커보드 배경**이 표시되고 나머지 기능은 그대로 동작합니다.
상단 `체커보드 배경` 체크로 배경을 바꿀 수 있습니다.

### libmpv 지정

탐색 순서는 다음과 같습니다:

1. 환경변수 `YTTSTUDIO_MPV_PATH` (파일 경로 또는 디렉터리)
2. 앱 실행 디렉터리
3. OS 표준 라이브러리 경로

```
set YTTSTUDIO_MPV_PATH=C:\path\to\libmpv-2.dll
```

libmpv 2.0 미만은 거부되며, 어떤 버전을 어디서 찾았는지 메시지에 표시됩니다.

## 2. 기본 흐름

```
자막 열기(.ytt/.ass)  또는  프로젝트 열기(.yttproj)
        ↓
영상 열기 (선택)
        ↓
캔버스에서 배치 · 속성 패널에서 스타일링
        ↓
검사 실행으로 유튜브 제약 확인
        ↓
YTT 저장  또는  프로젝트 저장
```

창에 파일을 드래그 앤 드롭해도 열 수 있습니다. 자막은 `.ytt` / `.srv3` / `.ass`, 영상은
`.mp4` / `.mkv` / `.webm` / `.mov` / `.avi` / `.m4v`를 지원합니다. `.yttproj`는 프로젝트 열기를
사용하세요. 여러 파일을 드롭하면 지원되는 파일을 전달된 순서대로 처리합니다.

### 파일 종류

| 확장자 | 용도 |
|---|---|
| `.yttproj` | **네이티브 프로젝트.** 스타일·트랙·효과·영상 경로를 모두 보존 |
| `.ytt` / `.srv3` | 유튜브 업로드용 최종 산출물 |
| `.ass` | Aegisub 왕복 |

> **`.ytt`는 편집 정보를 전부 담지 못합니다.** 효과가 키프레임으로 펼쳐져 있어 되읽어도
> 효과로 복원되지 않고, 트랙과 그리기 순서도 보존되지 않습니다.
> **작업 중인 파일은 `.yttproj`로 저장하세요.**

## 3. 캔버스 편집

| 동작 | 결과 |
|---|---|
| 큐 클릭 / Ctrl+클릭 | 선택 / 다중 선택 |
| 빈 곳 드래그 | 범위 선택 |
| 큐 드래그 | 위치 이동 |
| Shift+드래그 | 한 축 고정 |
| 방향키 / Shift+방향키 | 1% / 0.1% 이동 |
| 더블클릭 | 텍스트 편집 |
| 앵커 마커 클릭 | 앵커 변경 (화면 위치는 유지) |
| Alt 누른 채 드래그 | 스냅 일시 해제 |

### 앵커(ap)와 박스 내부 정렬(ju)은 다릅니다

- **앵커** — 박스의 *어느 점*을 좌표에 고정할지
- **박스 내부 정렬** — 박스 *안에서* 여러 줄이 어떻게 정렬될지 (한 줄이면 차이 없음)

두 값은 독립적으로 저장됩니다.

### 회전과 크기 핸들이 없는 이유

**YTT 포맷에 회전과 자유 스케일이 없습니다.** 크기는 속성 패널의 폰트 크기로만 조절합니다.
넣어두면 화면에서는 돌아가는데 결과물에 반영되지 않아 더 나쁩니다.

## 4. 스타일

`스타일 프리셋` 패널에서 만들고, `선택 스타일 적용`으로 큐에 붙입니다.
목록에서 고르는 것과 큐에 적용하는 것은 **별개 동작**입니다.

**스타일을 삭제하면** 그 스타일을 쓰던 큐는 삭제 직전의 모양 그대로 굳습니다.
외형이 갑자기 변하지 않습니다.

### 폰트는 8종 고정

YTT는 폰트를 8종 중에서만 고를 수 있습니다. 임의 폰트는 불가능합니다.
Roboto와 Liberation 계열은 앱에 포함돼 어느 OS에서도 동일하게 보이지만,
Lucida Console · Comic Sans MS · Monotype Corsiva는 재배포가 불가능해
**로컬에 없으면 근사 표시**됩니다. 그 경우 미리보기에 표시가 뜹니다.

### 크기 75%가 하한인 이유

포맷 제약입니다. 유튜브는 `sz` 값을 그대로 쓰지 않고 `실제 = 1 + (sz/100 - 1) / 4`로
압축하기 때문에 `sz=0`이어도 75% 아래로 내려가지 않습니다.
슬라이더는 200%까지지만 숫자 입력으로 더 키울 수 있습니다.

## 5. 가라오케

1. 큐를 선택하고 `가라오케 편집` 탭
2. `자동 음절 분할` — 한글은 글자, 일본어는 가나(요음 결합), 라틴은 단어 단위
3. 칩 사이 `분할` / `병합`으로 경계 조정
4. **탭 입력** — 재생하면서 `Space`로 현재 음절 시각을 찍고, `Backspace`로 직전 탭 취소
   - **0.5x 재생을 권장**합니다
   - 이 영역에서 `Space`는 재생/일시정지가 아니라 탭 입력입니다
5. 음절 타임라인 바에서 미세 조정

인접 음절이 같은 시각이 되면 업로드 과정에서 가라오케가 깨지므로 **자동으로 1ms를 띄웁니다.**

## 6. 효과

`이동 · 페이드 · 흔들림 · 색수차 · 애니메이션` 5종을 켤 수 있습니다.
현재는 기본 파라미터로 적용되며 세부 값 편집 UI는 아직 없습니다.

**흔들림은 결정적입니다** — 같은 프레임으로 되감으면 자막이 항상 같은 자리에 있습니다.

> 미리보기는 **편집용 근사치**입니다. 글로우 반경·외곽선 두께·줄바꿈 지점은 실제 유튜브와
> 미세하게 다릅니다. 최종 확인은 실제 업로드로 하세요.

## 7. 검증

`검사 실행`을 누르면 유튜브 제약 위반을 검사합니다.

| 등급 | 의미 |
|---|---|
| Error | 업로드하면 확실히 깨짐 |
| Warning | 깨질 수 있음 |
| Info | 참고 (PC 전용 기능 사용 등) |

`자동 수정`이 있는 항목은 버튼으로 고칠 수 있고, **Undo로 되돌릴 수 있습니다.**

### 파일 크기 경고(W101)를 믿지 마세요

브라우저의 실제 기준은 **JSON3로 변환된 파일의 압축 크기**인데, 앱은 그걸 계산할 수 없어
**gzip(XML) 근사치**를 씁니다. 안전 마진 70%에서 미리 경고합니다.

**경고가 없다고 안전하다는 뜻이 아닙니다.** 실제 표시 여부는 업로드 후 확인하세요.

## 8. 저장과 복구

### 자동 저장

편집 중이면 일정 간격으로 `%TEMP%/YttStudio/autosave/`에 복구본을 씁니다.
기본 간격은 **60초**이며, **도구 → 설정 → 일반**에서 끄거나 간격을 바꿀 수 있습니다.
변경은 재시작 없이 즉시 반영됩니다.

자동 저장은 **Undo 기록에 영향을 주지 않습니다.**

비정상 종료 후 다시 켜면 복구 여부를 묻습니다. 정상 종료 시에는 복구본이 지워집니다.

### 영상을 못 찾을 때

프로젝트는 **영상 경로만** 저장합니다. 영상을 옮기거나 이름을 바꾸면
프로젝트를 열 때 `다시 찾기` 대화상자가 뜹니다.

---

## 9. 검색·치환과 시간 이동

속성 패널의 `검색 / 치환`에서 정규식과 대소문자 구분을 켤 수 있습니다.
`시간 이동`은 선택한 큐 또는 전체를 밀거나 당깁니다.
시작 시각이 1ms 아래로 내려가지 않도록 자동으로 막습니다 — `t=0`은 안드로이드에서
자막이 아예 안 뜨는 원인입니다.

## 10. 환경설정

**도구 → 설정**에서 엽니다. 값은 `%LOCALAPPDATA%\YttStudio\preferences.json`에 저장되어
다음 실행에도 유지됩니다.

| 탭 | 항목 |
|---|---|
| 일반 | 언어(한국어 / English / 日本語), 자동 저장 사용 여부와 간격 |
| 모양 | 테마 — 시스템 기본 / 라이트 / 다크 |
| 영상 | libmpv 경로 선택, 자동 설치, 현재 상태, 라이선스 고지 |

언어와 테마는 **재시작 없이 즉시** 반영됩니다.

### libmpv 자동 설치와 라이선스

공식 Windows mpv 빌드는 **GPLv2+** 입니다. 그래서 YttStudio 배포물에는 libmpv 바이너리가
들어 있지 않습니다. 설정 창의 자동 설치는 출처와 라이선스를 표시한 뒤 **버튼을 눌렀을 때만**
내려받아 사용자 컴퓨터에 설치합니다. macOS 와 Linux 에서는 자동 설치 대신 패키지 매니저
명령을 안내합니다. 설치하거나 경로를 바꾸면 재시작 없이 다시 탐색합니다.

## 11. 화면 조작

### 타임라인

| 입력 | 동작 |
|---|---|
| `Ctrl` / `Alt` + 휠 | 가로 확대·축소 (마우스 커서 아래 시각이 고정) |
| `Shift` + 휠 | 좌우 이동 |
| 가운데 버튼 드래그 | 핸드 팬 |
| 스크롤바 드래그 | 좌우 이동 |
| 블록 몸통 드래그 | 큐 이동 |
| 블록 좌우 끝 드래그 | 시작·끝 트림 |
| 빈 곳 클릭·드래그 | 재생 헤드 이동 |

확대하지 않은 상태에서는 전체 구간이 이미 보이므로 좌우 이동이 일어나지 않습니다.
스크롤바의 폭이 현재 보이는 범위를 나타냅니다.

### 패널 크기

패널 사이의 경계를 끌어 좌·우 패널의 너비와 영상 / 타임라인 / 자막 목록의 높이를
조절할 수 있습니다. 최소 크기가 정해져 있어 패널이 완전히 사라지지는 않습니다.

### 재생 컨트롤

재생 버튼은 정지 중 `▶`, 재생 중 `⏸` 로 표시됩니다. 옆의 슬라이더로 볼륨을 조절하고
`음소거` 로 소리를 끌 수 있으며, 볼륨은 다음 실행에도 유지됩니다.

영상을 연 뒤 창에서 `Space`를 누르면 재생과 일시정지를 전환합니다. 텍스트 편집, 타임라인,
가라오케 입력 영역에 포커스가 있으면 해당 영역의 `Space` 입력이 우선합니다.

**영상을 열어도 자동으로 재생되지 않습니다.** 첫 프레임에서 멈춘 상태로 열리며,
재생 버튼을 눌러야 시작합니다.

## 12. 알려진 제약

- **뷰포트 모드**(일반/극장/전체화면/모바일)는 **비활성**입니다.
  실제 좌표 동작을 측정하기 전에는 추측으로 구현하지 않습니다.
- **오디오 파형**은 표시되지 않습니다. 실제 샘플을 얻는 경로가 없어 가짜 파형을 그리지 않습니다.
- 효과 세부 파라미터 편집 UI가 없습니다.
- mitmproxy 실제 플레이어 프리뷰는 스크립트만 있고 실행 UI가 없습니다.

## 14. 캔버스에서 cue 만들기와 실행 취소

미리보기에서 cue가 없는 빈 영역을 더블클릭하면 현재 재생 시각을 시작 시각으로 하여 2초 길이의 cue가 생성됩니다. 클릭한 화면 위치는 캔버스 좌표로 변환되고 유효한 범위로 제한됩니다. 새 cue는 즉시 선택되며 인라인 텍스트 입력 상자가 열립니다.

기존 동작도 그대로 사용할 수 있습니다. cue를 한 번 클릭하면 선택하고, 선택된 cue를 드래그하면 위치를 옮깁니다. cue를 더블클릭하면 해당 cue의 텍스트를 인라인으로 편집합니다. 빈 영역을 한 번 누른 뒤 드래그하면 범위 선택이 됩니다.

창에 포커스가 있을 때 `Ctrl+Z`는 실행 취소, `Ctrl+Y` 또는 `Ctrl+Shift+Z`는 다시 실행입니다. 실행할 수 없는 명령은 단축키가 가로채지 않습니다. 텍스트 상자에 포커스가 있으면 이 단축키를 창에서 처리하지 않고 텍스트 상자의 기본 undo/redo를 사용합니다.

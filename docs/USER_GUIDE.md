# yttStudio 사용자 가이드

> **문서 기준:** v0.2.5 (2026-08-30)

## v0.2.5 영상 재생 첫 사용 흐름

로컬 영상 또는 YouTube 주소 열기는 libmpv가 아직 없는 첫 실행에서도 사용할 수 있다. 기존 호환 libmpv를 찾지 못하면 지원 플랫폼에서 프로그램이 검증된 LGPL 런타임을 사용자 영역에 설치하고, 완료 후 사용자가 처음 요청한 영상을 그대로 연다. YouTube 주소에서는 yt-dlp와 현재 YouTube JavaScript challenge 처리에 필요한 Deno 2.3+도 확인하며, 없으면 각각 공식 고정 자산을 검증 설치한다. 설정의 **영상** 페이지에서는 libmpv 재설치와 수동 경로 지정도 가능하다.

YouTube YTT(SRV3) 자막 전용 WYSIWYG 에디터. 영상 위에서 직접 배치·스타일링하고 `.ytt`를 뽑습니다.

> **언어 / Language / 言語** — 도구 → 설정 → 일반에서 한국어 · English · 日本語를 전환합니다.
> 전환은 즉시 반영됩니다.

## 1. 시작하기

### 필요한 것

| 항목 | 비고 |
|---|---|
| .NET 10 런타임 | self-contained 빌드를 쓰면 불필요 |
| libmpv | **영상 재생에 필요.** 없어도 자막 편집·저장은 정상 동작 |
| yt-dlp | **YouTube 주소 미리보기에 필요.** 없으면 공식 2026.08.19 자산을 사용자 영역에 검증 설치 |
| Deno 2.3+ | **현재 yt-dlp의 YouTube JavaScript challenge 처리에 필요.** 없으면 공식 v2.9.6 자산을 사용자 영역에 검증 설치 |

### libmpv 없이 쓰기

libmpv를 찾지 못하면 영상 대신 **단색/체커보드 배경**이 표시되고 나머지 기능은 그대로 동작합니다.
상단 `체커보드 배경` 체크로 배경을 바꿀 수 있습니다.

### libmpv 지정

탐색 순서는 다음과 같습니다:

1. 환경변수 `YTTSTUDIO_MPV_PATH` (파일 경로 또는 디렉터리)
2. 앱 실행 디렉터리
3. OS 표준 라이브러리 경로

```
set YTTSTUDIO_MPV_PATH=C:\path\to\libmpv-2.dll
```

libmpv 2.0 미만은 거부되며, 어떤 버전을 어디서 찾았는지 메시지에 표시됩니다.

### YouTube 주소 미리보기 준비

지원 플랫폼에서는 별도 도구를 미리 설치할 필요가 없습니다. 주소를 처음 열 때 yttStudio가 다음 순서로 준비합니다.

1. Deno 2.3 이상을 `YTTSTUDIO_DENO_PATH`와 `PATH`에서 찾습니다.
2. 없으면 공식 `denoland/deno v2.9.6` 자산을 사용자 영역에 내려받고 크기·SHA-256·실제 버전을 검증합니다.
3. `yt-dlp`를 `YTTSTUDIO_YTDLP_PATH`, 앱 경로와 `PATH`에서 찾습니다.
4. 없으면 공식 `yt-dlp/yt-dlp 2026.08.19` 자산을 SHA-256 검증 후 사용자 영역에 설치합니다.
5. yt-dlp 사전 확인에 관리 Deno 경로를 명시하고, libmpv `ytdl_hook`에서도 같은 Deno를 찾을 수 있도록 현재 프로세스 `PATH`에 등록합니다.

이 런타임들은 yttStudio 릴리스 파일 안에 직접 포함되지 않으며 실행 시 각 공식 upstream에서 받습니다. Windows의 관리 실행 파일은 `deno.exe`와 `yt-dlp.exe`이며 macOS/Linux에서는 `deno`와 `yt-dlp`입니다.

YouTube가 `HTTP 403`, `HTTP 429` 또는 bot challenge로 요청을 거부한 경우에는 더 이상 일반 **네트워크 실패**로 표시하지 않습니다. DNS·연결 실패·5xx 응답과 YouTube 접근 거부를 분리해 안내합니다.

## 2. 기본 흐름

```
자막 열기(.ytt/.ass)  또는  프로젝트 열기(.yttproj)
        ↓
영상 열기 또는 주소로 열기 (선택)
        ↓
캔버스에서 배치 · 속성 패널에서 스타일링
        ↓
검사 실행으로 유튜브 제약 확인
        ↓
YTT 저장  또는  프로젝트 저장
```

창에 파일을 드래그 앤 드롭해도 열 수 있습니다. 자막은 `.ytt` / `.srv3` / `.ass`, 영상은
`.mp4` / `.mkv` / `.webm` / `.mov` / `.avi` / `.m4v`를 지원합니다. `.yttproj`는 프로젝트 열기를
사용하세요. 여러 파일을 드롭하면 지원되는 파일을 전달된 순서대로 처리합니다.

### 파일 종류

| 확장자 | 용도 |
|---|---|
| `.yttproj` | **네이티브 프로젝트.** 스타일·트랙·효과·영상 경로를 모두 보존 |
| `.ytt` / `.srv3` | 유튜브 업로드용 최종 산출물 |
| `.ass` | Aegisub 왕복 |

> **`.ytt`는 편집 정보를 전부 담지 못합니다.** 효과가 키프레임으로 펼쳐져 있어 되읽어도
> 효과로 복원되지 않고, 트랙과 그리기 순서도 보존되지 않습니다.
> **작업 중인 파일은 `.yttproj`로 저장하세요.**

### YouTube 주소로 열기

도구 모음 또는 `파일 → 주소로 열기`를 선택하고 YouTube 주소를 붙여 넣은 뒤 확인합니다.
지원하는 대표 형식은 다음과 같습니다.

- `https://www.youtube.com/watch?v=...`
- `https://youtu.be/...`

주소를 입력하면 앱이 형식을 확인한 뒤 `yt-dlp`와 libmpv의 `ytdl_hook`을 통해 VOD
스트림을 엽니다. 영상 파일을 내려받아 저장하지 않습니다. 주소로 연 영상도 로컬 영상과
같이 재생·정지, 탐색, 프레임 앞뒤 이동, 재생 속도, 볼륨·음소거를 사용할 수 있습니다.
네트워크 상태와 영상의 키프레임에 따라 첫 화면이나 탐색이 로컬 파일보다 늦을 수
있습니다.

영상이 재생되는 동안 캔버스의 자막을 끌어 옮기고, 바깥 조절점 여덟 개로 크기를
조절하며, 타임라인에서 구간의 시작·끝·몸통을 끄는 동작도 로컬 영상과 같은 편집
경로를 사용합니다. 영상이 없어도 자막 편집 자체는 계속할 수 있습니다.

오류는 원인을 섞어 안내하지 않습니다.

| 상황 | 안내되는 사유 | 다음 조치 |
|---|---|---|
| 주소가 URL이 아니거나 YouTube 주소 형식이 아님 | **주소 형식 오류** | `watch` 또는 `youtu.be` 주소를 다시 입력 |
| 자동 런타임 준비 자체가 실패함 | **재생 도구 준비 실패** | 로그의 Deno/yt-dlp 다운로드·검증 오류를 확인하고 다시 시도 |
| 주소는 맞지만 YouTube/CDN에 연결하지 못함 | **네트워크 실패** | 네트워크·프록시·방화벽을 확인한 뒤 다시 시도 |
| YouTube가 HTTP 403·429 또는 bot challenge로 요청을 거부함 | **접근 거부** | 잠시 후 다시 시도. 반복되면 yt-dlp/YouTube 쪽 변경 여부 확인 |
| 생방송·연령 제한·비공개·지역 차단 등으로 재생할 수 없음 | **재생할 수 없는 영상** | 재생 가능한 공개 VOD 주소를 사용 |

어느 오류에서도 앱이 종료되거나 기존 자막 편집이 사라지지 않아야 합니다. `yt-dlp`가
없어도 로컬 영상과 자막 편집·저장은 사용할 수 있습니다.

## 3. 캔버스 편집

| 동작 | 결과 |
|---|---|
| 큐 클릭 / Ctrl+클릭 | 선택 / 다중 선택 |
| 빈 곳 드래그 | 범위 선택 |
| 큐 드래그 | 위치 이동 |
| Shift+드래그 | 한 축 고정 |
| 방향키 / Shift+방향키 | 1% / 0.1% 이동 |
| 더블클릭 | 텍스트 편집 |
| 바깥 조절점 8개 드래그 | **맞은편이 고정된 채** 끄는 방향으로 커짐 (YTT `SizePercent` 배율) |
| 조절점 클릭 (끌지 않음) | 그 점을 앵커로 지정 (화면 위치는 유지) |
| 가운데 점 클릭 | 가운데를 앵커로 지정 — 이 점은 크기를 바꾸지 않습니다 |
| `Shift` + 조절점 드래그 | 더 정밀한 폰트 배율 조절 |
| Alt 누른 채 드래그 | 스냅 일시 해제 |
| 프리뷰에서 `Delete` | 선택 cue 삭제 (인라인 편집 중에는 동작하지 않음) |
| 큐 목록에서 `Delete` | 행 TextBox가 아닌 곳에 포커스가 있을 때 선택 cue 삭제 |

### 조절점 하나가 크기와 앵커를 겸합니다

선택 박스에는 3x3로 점 아홉 개가 붙습니다. **바깥 여덟 개는 사각형**으로 그려지며 크기
조절점이고, **가운데 하나는 원**으로 그려지며 앵커 전용입니다. 바깥 점은 누른 뒤 실제로 끌면
크기가 바뀌고, 끌지 않고 그냥 떼면 그 점이 앵커가 됩니다. 그래서 점 하나로 두 가지를 다 할 수
있고, 앵커를 고르려던 손이 크기를 건드리는 일도 없습니다. 현재 앵커인 점은 자홍색으로
칠해집니다.

### 앵커(ap)와 박스 내부 정렬(ju)은 다릅니다

- **앵커** — 박스의 *어느 점*을 좌표에 고정할지
- **박스 내부 정렬** — 박스 *안에서* 여러 줄이 어떻게 정렬될지 (한 줄이면 차이 없음)

두 값은 독립적으로 저장됩니다.

### 회전과 자유 크기 조절이 없는 이유

**YTT 포맷에 회전과 자유로운 박스 스케일이 없습니다.** 프리뷰의 조절점은 박스의
가로·세로를 각각 다르게 늘일 수 없고, 폰트 크기 배율인 `SizePercent` 하나만 바꿉니다.
따라서 가로세로 비율은 항상 유지됩니다.

다만 **자라는 방향은 프리미어와 같습니다.** 조절점을 잡으면 그 **맞은편 점이 고정점**이 되고,
잡은 점을 끄는 방향으로만 박스가 자랍니다. 오른쪽 가운데 점을 끌면 왼쪽 변이 제자리에 있고
오른쪽으로 커지며, 왼쪽 위 모서리를 끌면 오른쪽 아래 모서리가 제자리에 있습니다. 고정점을
유지하기 위해 앵커 좌표(`ah`/`av`)가 함께 보정되지만, 앵커 종류(`ap`)는 바뀌지 않습니다.
고정변과 나란한 방향으로만 움직이면 크기는 변하지 않습니다.
따라서 프리뷰를 다시 배치하거나 크기를 바꿔도 export 가능한 YTT 값으로 유지됩니다. 선택된
cue가 여러 개면 같은 배율을 적용하고, 앵커를 기준으로 한 위치는 고정됩니다. 합리적인 최소·최대
배율로 제한되며 `Shift`를 누르면 더 정밀하게 조절할 수 있습니다. 컨텍스트 메뉴의
`NoFreeScale`은 자유 박스 스케일이 지원되지 않는다는 뜻이며, 이 폰트 배율 조절과 모순되지
않습니다. `Alt`는 위치 드래그에서 기존 스냅 해제 용도로 유지되며, 리사이즈를 자유 스케일로
바꾸지 않습니다.

## 4. 스타일

`스타일 프리셋` 패널에서 만들고, `선택 스타일 적용`으로 큐에 붙입니다.
목록에서 고르는 것과 큐에 적용하는 것은 **별개 동작**입니다.

**스타일을 삭제하면** 그 스타일을 쓰던 큐는 삭제 직전의 모양 그대로 굳습니다.
외형이 갑자기 변하지 않습니다.

### 색은 적어도 되고 골라도 됩니다

전경 · 배경 · 테두리 색은 `#RRGGBB` 또는 `#RRGGBBAA` 로 직접 적을 수 있습니다.
입력란 오른쪽 칸은 지금 색을 보여 주며, 누르면 여덟 색 팔레트가 열립니다.
유튜브 자막 설정이 제공하는 색과 같습니다. 팔레트에 없는 색은 직접 적으세요.

**팔레트에서 고르면 불투명도는 바뀌지 않습니다.** 색과 불투명도는 따로 다룹니다.
불투명도는 바로 아래의 0–255 입력으로 조절합니다.

여러 큐를 골랐는데 색이 서로 다르면 입력란에 `—` 가 오고 미리보기 칸은 비어
있습니다. 이때 색을 고르면 고른 큐 전부에 같은 색이 들어갑니다.

### 폰트는 8종 고정

YTT는 폰트를 8종 중에서만 고를 수 있습니다. 임의 폰트는 불가능합니다.
Roboto와 Liberation 계열은 앱에 포함돼 어느 OS에서도 동일하게 보이지만,
Lucida Console · Comic Sans MS · Monotype Corsiva는 재배포가 불가능해
**로컬에 없으면 근사 표시**됩니다. 그 경우 미리보기에 표시가 뜹니다.

### 크기 75%가 하한인 이유

포맷 제약입니다. 유튜브는 `sz` 값을 그대로 쓰지 않고 `실제 = 1 + (sz/100 - 1) / 4`로
압축하기 때문에 `sz=0`이어도 75% 아래로 내려가지 않습니다.
슬라이더는 200%까지지만 숫자 입력으로 더 키울 수 있습니다.

## 5. 가라오케

1. 큐를 선택하고 `가라오케 편집` 탭
2. `자동 음절 분할` — 한글은 글자, 일본어는 가나(요음 결합), 라틴은 단어 단위
3. 칩 사이 `분할` / `병합`으로 경계 조정
4. **탭 입력** — 재생하면서 `Space`로 현재 음절 시각을 찍고, `Backspace`로 직전 탭 취소
   - **0.5x 재생을 권장**합니다
   - 이 영역에서 `Space`는 재생/일시정지가 아니라 탭 입력입니다
5. 음절 타임라인 바에서 미세 조정

인접 음절이 같은 시각이 되면 업로드 과정에서 가라오케가 깨지므로 **자동으로 1ms를 띄웁니다.**

## 6. 효과

`이동 · 페이드 · 흔들림 · 색수차 · 애니메이션` 5종을 켤 수 있습니다.
현재는 기본 파라미터로 적용되며 세부 값 편집 UI는 아직 없습니다.

**흔들림은 결정적입니다** — 같은 프레임으로 되감으면 자막이 항상 같은 자리에 있습니다.

> 미리보기는 **편집용 근사치**입니다. 글로우 반경·외곽선 두께·줄바꿈 지점은 실제 유튜브와
> 미세하게 다릅니다. 최종 확인은 실제 업로드로 하세요.

## 7. 검증

`검사 실행`을 누르면 유튜브 제약 위반을 검사합니다.

| 등급 | 의미 |
|---|---|
| Error | 업로드하면 확실히 깨짐 |
| Warning | 깨질 수 있음 |
| Info | 참고 (PC 전용 기능 사용 등) |

`자동 수정`이 있는 항목은 버튼으로 고칠 수 있고, **Undo로 되돌릴 수 있습니다.**

### 파일 크기 경고(W101)를 믿지 마세요

브라우저의 실제 기준은 **JSON3로 변환된 파일의 압축 크기**인데, 앱은 그걸 계산할 수 없어
**gzip(XML) 근사치**를 씁니다. 안전 마진 70%에서 미리 경고합니다.

**경고가 없다고 안전하다는 뜻이 아닙니다.** 실제 표시 여부는 업로드 후 확인하세요.

## 8. 저장과 복구

### 저장 도중 문제가 생겨도 원본은 남습니다

저장할 때 기존 파일을 바로 덮어쓰지 않습니다. 같은 폴더에 임시 파일로 먼저 쓰고, 끝까지
성공했을 때만 바꿔치기합니다. 저장 도중 디스크가 차거나 프로그램이 멈춰도 직전에 저장해 둔
파일은 그대로 있습니다.

### 자동 저장

편집 중이면 일정 간격으로 `%TEMP%/YttStudio/autosave/`에 복구본을 씁니다.
기본 간격은 **60초**이며, **도구 → 설정 → 일반**에서 끄거나 간격을 바꿀 수 있습니다.
변경은 재시작 없이 즉시 반영됩니다.

자동 저장은 **Undo 기록에 영향을 주지 않습니다.**

비정상 종료 후 다시 켜면 복구 여부를 묻습니다. 정상 종료 시에는 복구본이 지워집니다.

### 영상을 못 찾을 때

프로젝트는 **영상 경로만** 저장합니다. 영상을 옮기거나 이름을 바꾸면
프로젝트를 열 때 `다시 찾기` 대화상자가 뜹니다.

## 10. 환경설정

**도구 → 설정**에서 엽니다. 값은 `%LOCALAPPDATA%\YttStudio\preferences.json`에 저장되어
다음 실행에도 유지됩니다.

| 탭 | 항목 |
|---|---|
| 일반 | 언어(한국어 / English / 日本語), 자동 저장 사용 여부와 간격 |
| 모양 | 테마 — 시스템 기본 / 라이트 / 다크 |
| 영상 | libmpv 경로 선택, 자동 설치, 현재 상태, 라이선스 고지 |

언어와 테마는 **재시작 없이 즉시** 반영됩니다.

### libmpv 자동 설치와 라이선스

공식 Windows mpv 빌드는 **GPLv2+** 입니다. 그래서 yttStudio 배포물에는 libmpv 바이너리가
들어 있지 않습니다. 설정 창의 자동 설치는 출처와 라이선스를 표시한 뒤 **버튼을 눌렀을 때만**
내려받아 사용자 컴퓨터에 설치합니다. macOS 와 Linux 에서는 자동 설치 대신 패키지 매니저
명령을 안내합니다. 설치하거나 경로를 바꾸면 재시작 없이 다시 탐색합니다.

---

**받은 파일은 확인한 뒤에 씁니다.** 설치할 mpv 빌드를 특정 버전으로 못박아 두고, 내려받은
파일의 SHA-256 이 그 값과 같을 때만 압축을 풉니다. 다르면 지우고 설치를 멈춥니다. 최신
빌드를 자동으로 따라가지 않는 이유가 이것입니다 — 무엇이 올지 모르는 파일을 프로그램 안에
불러올 수는 없기 때문입니다. 새 버전은 앱 업데이트로 올라갑니다.

## 11. 화면 조작

### 타임라인

| 입력 | 동작 |
|---|---|
| `Ctrl` / `Alt` + 휠 | 가로 확대·축소 (마우스 커서 아래 시각이 고정) |
| `Shift` + 휠 | 좌우 이동 |
| 가운데 버튼 드래그 | 핸드 팬 |
| 스크롤바 드래그 | 좌우 이동 |
| 블록 몸통 드래그 | 큐 이동 |
| 블록 좌우 끝 드래그 | 시작·끝 트림 |
| 빈 곳 클릭·드래그 | 재생 헤드 이동 |

확대하지 않은 상태에서는 전체 구간이 이미 보이므로 좌우 이동이 일어나지 않습니다.
스크롤바의 폭이 현재 보이는 범위를 나타냅니다.

### 패널 크기

패널 사이의 경계를 끌어 좌·우 패널의 너비와 영상 / 타임라인 / 자막 목록의 높이를
조절할 수 있습니다. 최소 크기가 정해져 있어 패널이 완전히 사라지지는 않습니다.

### 재생 컨트롤

재생 버튼은 정지 중 `▶`, 재생 중 `⏸` 로 표시됩니다. 옆의 슬라이더로 볼륨을 조절하고
`음소거` 로 소리를 끌 수 있으며, 볼륨은 다음 실행에도 유지됩니다.

영상을 연 뒤 창에서 `Space`를 누르면 재생과 일시정지를 전환합니다. 텍스트 편집, 타임라인,
가라오케 입력 영역에 포커스가 있으면 해당 영역의 `Space` 입력이 우선합니다.

**영상을 열어도 자동으로 재생되지 않습니다.** 첫 프레임에서 멈춘 상태로 열리며,
재생 버튼을 눌러야 시작합니다.

### 재생 화질

도구 막대에서 `원본` · `1/2` · `1/4` · `1/8` 을 고를 수 있습니다. 선택은 다음 실행에도
유지됩니다.

이것은 **화면에 받아 오는 크기**를 줄이는 설정입니다. 디코딩은 원본 해상도로 그대로
일어나므로, 줄어드는 것은 그 뒤의 전송과 화면 합성 몫입니다. 고해상도 영상에서 편집이
버벅이면 낮춰 보세요. **내보내는 자막에는 아무 영향이 없습니다.**

### 위치를 빠르게 옮길 때

타임라인이나 슬라이더를 끌면 위치가 포인터를 따라 계속 바뀝니다. 그때마다 영상을 새로
디코딩하면 부하가 감당이 안 되므로, 실제 탐색은 **최소 70ms 간격**으로 나갑니다. 끄는
도중의 중간 지점은 합쳐지고 마지막 위치가 우선됩니다(latest-wins). 따라서 포인터를
놓은 뒤 마지막 위치로 수렴하며, 중간 요청을 모두 보내 디코더나 네트워크 스트림을
반복해서 되감지 않습니다. 이 제한은 로컬 파일뿐 아니라 YouTube 스트림에도 적용됩니다.
주소 영상은 네트워크와 키프레임 때문에 최종 위치에 도달하는 시간이 더 길 수 있지만,
마지막으로 요청한 위치를 버리지 않는 것이 기준입니다.

일반 재생에는 적용되지 않습니다. 재생 중에는 탐색이 일어나지 않고 프레임이 그대로
나옵니다.

## 14. 캔버스에서 cue 만들기와 실행 취소

미리보기에서 cue가 없는 빈 영역을 더블클릭하면 현재 재생 시각을 시작 시각으로 하여 2초 길이의 cue가 생성됩니다. 클릭한 화면 위치는 캔버스 좌표로 변환되고 유효한 범위로 제한됩니다. 새 cue는 즉시 선택되며 인라인 텍스트 입력 상자가 열립니다.

기존 동작도 그대로 사용할 수 있습니다. cue를 한 번 클릭하면 선택하고, 선택된 cue를 드래그하면 위치를 옮깁니다. cue를 더블클릭하면 해당 cue의 텍스트를 인라인으로 편집합니다. 빈 영역을 한 번 누른 뒤 드래그하면 범위 선택이 됩니다.

창에 포커스가 있을 때 `Ctrl+Z`는 실행 취소, `Ctrl+Y` 또는 `Ctrl+Shift+Z`는 다시 실행입니다. 실행할 수 없는 명령은 단축키가 가로채지 않습니다. 텍스트 상자에 포커스가 있으면 이 단축키를 창에서 처리하지 않고 텍스트 상자의 기본 undo/redo를 사용합니다.

### 자막처럼 보이는 WYSIWYG 인라인 편집

인라인 편집기는 별도의 흰색 입력 창이 아니라 자막 위치에 겹쳐 놓은 실제 Avalonia `TextBox`입니다.
배경과 테두리는 투명하게 하고, 큐의 해석된 스타일에서 폰트 패밀리·크기·전경색·불투명도·수평
정렬(`Justification`)을 가져와 프리뷰 배율에 맞춰 적용합니다. 여러 줄과 줄바꿈도 같은 TextBox에서
편집되므로 캐럿·선택·클립보드 및 한글/일본어 IME 조합 입력을 그대로 사용할 수 있습니다. 입력 중인
텍스트는 `InlineText`를 통해 프리뷰에 실시간 반영되고, 편집 중인 cue는 `SubtitleImage` 래스터에서
제외되어 자막이 두 번 그려지지 않습니다.

TextBox는 YTT의 엣지·그림자·외곽선을 정확히 재현할 수 없습니다. 여러 section이 섞인 스타일이나
가라오케의 음절 단위 표현도 제자리 편집에서 정확히 재현되지 않습니다. 이 차이는 근사하지 않고
문서화된 한계로 남깁니다.

### 인라인 편집 확정·취소

미리보기 캔버스에 포커스가 있고 cue를 정확히 하나 선택한 상태에서 `F2` 또는 `Enter`를 누르면 선택한 cue의 인라인 편집을 시작합니다. 입력 상자는 선택한 cue의 화면 박스를 기준으로 놓이며, 프리뷰 영역(`Border` 안쪽) 밖으로 잘리지 않도록 자동으로 클램프됩니다. 기존 cue를 더블클릭하거나 빈 영역을 더블클릭해 새 cue를 만든 뒤에도 같은 입력 상자를 사용합니다.

| 입력 | 동작 |
|---|---|
| `Enter` | 현재 텍스트를 커밋하고 편집을 끝냅니다 |
| `Shift+Enter` | 커밋하지 않고 텍스트에 줄바꿈을 넣습니다 |
| `Esc` | 편집을 취소합니다. 기존 cue는 편집 시작 전 텍스트로 복원되고, 새 cue는 추가 자체가 롤백됩니다 |
| 입력 상자 포커스 상실 | 현재 텍스트를 커밋하고 편집을 끝냅니다 |

인라인 `적용` 버튼은 표시하지 않습니다. `Enter` 또는 바깥 클릭으로 확정하고 `Esc`로 취소합니다.

입력 중 `InlineText`가 바뀌면 프리뷰의 자막 이미지도 즉시 갱신됩니다. 커밋 시 편집 세션 전체가 undo 기록 하나로 저장되므로, 글자마다 별도의 기록이 생기지 않습니다. 따라서 커밋 직후 `Ctrl+Z`를 한 번 누르면 편집 시작 전 텍스트로 돌아가고, `Ctrl+Y` 또는 `Ctrl+Shift+Z`로 세션 전체를 다시 적용할 수 있습니다. `Esc`로 취소한 세션은 undo 기록에 남지 않습니다.

### 큐 목록에서 `Delete`로 삭제

큐 목록에 포커스가 있고 선택된 행의 TextBox가 아닌 곳에서 `Delete`를 누르면 기존 삭제 명령으로
선택된 cue를 삭제합니다. 삭제 뒤에는 가능한 경우 이웃 행이 선택되고, 목록이 비면 선택도 비워집니다.
시작·끝 시각, Track, 텍스트 같은 행 내부 TextBox에 포커스가 있거나 인라인 편집 중이면 포커스
가드가 작동하여 `Delete`는 입력 중인 문자를 지우는 기본 동작으로 남고 cue를 삭제하지 않습니다.
